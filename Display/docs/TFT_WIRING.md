# Подключение 3.5" TFT (ST7796S, 4-wire SPI) к плате f407

Модуль: 9-контактный разъём «SPI» (левый край модуля, сверху вниз, «1» у GND).
Перемычки IM0–IM2 на модуле — по столбцу **SPI** таблицы на шелкографии.
Плата: вид сверху, координаты из `f407.brd`; пин 1 разъёмов — круглая площадка.

Всего 2 разъёма на плате (**SV4 + SV1**) — DC/RST перенесены с SV5 на SV1, где
уже стояла подсветка (BL), чтобы не тянуть провода к третьему разъёму. SV5 в
разводке TFT больше не участвует.

## Соединения (вариант А: SV4 + SV1, 9 проводов)

```
   МОДУЛЬ TFT (разъём SPI)                       ПЛАТА f407
   ┌──────────────┐
 1 │ GND          │────────────────────────────  SV4.6  GND
 2 │ VCC          │────────────────────────────  SV4.5  +5V   (*)
 3 │ SCL          │────────────────────────────  SV4.3  PC10  SPI3_SCK
 4 │ SDA          │────────────────────────────  SV4.1  PC12  SPI3_MOSI
 5 │ RST          │────────────────────────────  SV1.4  PB9
 6 │ DC           │────────────────────────────  SV1.5  PA4
 7 │ CS           │────────────────────────────  SV4.4  PA15
 8 │ BL           │────────────────────────────  SV1.3  PB8   (1 = подсветка вкл)
 9 │ SDA-O        │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   SV4.2  PC11  SPI3_MISO  (опц., только чтение ID)
   └──────────────┘
```

(*) +5V — если у модуля есть свой стабилизатор 3.3 V (обычно есть, на фото U8). Если модуль
чисто 3.3-вольтовый — VCC брать с **SV2.1 (+3V3)**.

PB9 и PA4 на этой плате подписаны как RPM2 (TIM4) и DAC_OUT1 (см. `hardware/BOARD.md`) —
это просто пример-разводка для других применений, в текущей прошивке DAC/TIM4 не
используются, так что оба пина свободны под обычный push-pull GPIO (тот же случай,
что и PB8/BL).

## Где эти пины на плате

```
 SV4 — левый край платы, 2×3
 (край платы слева)

   ┌───────┬───────┐
   │ 6 GND │ 5 +5V │  ← верх
   ├───────┼───────┤
   │ 4 CS  │ 3 SCK │
   │ PA15  │ PC10  │
   ├───────┼───────┤
   │ 2 MISO│ 1 MOSI│  ← низ, 1 = круглая
   │ PC11  │ PC12  │
   └───────┴───────┘

 SV1 — верхний край, 2×5, пин 1 справа (питания нет - все пины сигнальные)
   ┌──────┬──────┬──────┬──────┬──────┐
   │  9   │  7   │  5   │  3   │  1   │  ← верхний ряд (у края)
   │ PD5  │ PC6  │ PA4  │ PB8  │ PA0  │
   │      │      │  DC  │  BL  │      │
   ├──────┼──────┼──────┼──────┼──────┤
   │  10  │  8   │  6   │  4   │  2   │
   │ PD6  │ PC7  │ PA5  │ PB9  │ PA3  │
   │      │      │      │ RST  │      │
   └──────┴──────┴──────┴──────┴──────┘
```

BL/RST/DC занимают три соседних пина SV1 (3, 4, 5) — компактный жгут из трёх
проводов рядом друг с другом; пины 1-2 и 6-10 свободны.

## Вариант Б: без управления подсветкой (8 проводов)

То же, но **BL** модуля — на **SV2.1 (+3V3)** напрямую, минуя SV1.3/PB8: подсветка
всегда включена, без программного управления. SDA-O не подключать. В прошивке
`TFT_BL_Pin` в этом случае не используется.

```
 1 GND   → SV4.6        5 RST → SV1.4 (PB9)
 2 VCC   → SV4.5 (+5V)  6 DC  → SV1.5 (PA4)
 3 SCL   → SV4.3 (PC10) 7 CS  → SV4.4 (PA15)
 4 SDA   → SV4.1 (PC12) 8 BL  → SV2.1 (+3V3)
```

## Проверка перед включением
1. Мультиметром: между SV4.5 и SV4.6 нет КЗ после подключения модуля.
2. Провода SCL/SDA — короткие (< 15 см), GND — рядом с ними; на 20 MHz длинные шлейфы дают сбои.
3. После прошивки в USART1: `[tft] RDID4(0xD3) = xx 00 77 96` — если подключён SDA-O.
