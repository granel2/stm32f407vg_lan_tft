# Плата-адаптер 3.5" TFT (8080 / SPI)

Контроллер: не подписан. Режимы IM и 40-pin FPC совпадают с ILI9488 (320×480), проверить при инициализации (ID-регистр 0xD3).

## Разъёмы
- **40-pin FPC**: шлейф самой матрицы (pin 1 слева, 40 справа).
- **8080-8P (FPC, верх)**: GND, VCC, CS, DC, WR, RD, RST, D0…D7, BL
- **8080-16P (FPC11, низ)**: GND, VCC, CS, DC, WR, RD, RST, D0…D15, BL
- **SPI, штыревой 9-pin (шаг 2.54)**:

| Pin | Сигнал |
|---|---|
| 1 | GND (квадратная площадка) |
| 2 | VCC |
| 3 | SCL |
| 4 | SDA (MOSI) |
| 5 | RST |
| 6 | DC |
| 7 | CS |
| 8 | BL (подсветка) |
| 9 | SDA-O (MISO) |

## Выбор интерфейса — перемычки IM2/IM1/IM0
Резисторы 0 Ом (на плате маркировка 102/201 у текущих позиций) переставляются между положениями 0 и 1.

| Режим | IM2 | IM1 | IM0 |
|---|---|---|---|
| 8080 8-bit (P8) | 0 | 1 | 1 |
| 8080 16-bit (P16) | 0 | 1 | 0 |
| SPI 4-wire (с DC) | 1 | 1 | 1 |
| SPI 3-wire (SPI3, 9-bit) | 1 | 0 | 1 |

## Питание
- U8 — LDO 3.3 В (SOT-223, маркировка 6206A/7205-33): VCC можно подавать 5 В, логика 3.3 В.
- U7 — транзистор управления подсветкой (SOT-23), вход BL: высокий уровень = включено (проверить).
- Уровни сигналов данных — 3.3 В.
