# Keypad — приём пакетов от модуля клавиатуры 4×4

Модуль клавиатуры (ATmega328P, проект `..\..\atm328p_keyboard`) подключается к разъёму
**SV5** и сам передаёт пакеты по I²C. Эта плата — **ведомый `0x30`** на I2C1, только
принимает. Опроса и таймера нет: в простое процессор модулем не занят.

## Подключение

| SV5 | Сигнал | Модуль клавиатуры (Pro Mini) |
|---|---|---|
| 1 | GND | GND |
| 2 | +5V | RAW |
| 3 | SDA PB7 | A4 |
| 4 | SCL PB6 | A5 |

Подтяжки 4,7 кОм к +5 В стоят на модуле; на этой плате подтяжек нет, внутренние выключены
(PB6/PB7 — FT). ES0182 2.10.6: при VDD = 3,3 В шина допустима до 5,14 В (у модуля 5,02 В).
Скорость 100 кГц задаёт модуль.

## Протокол

`Inc/kbd_protocol.h` — **копия** `atm328p_keyboard/include/protocol.h`, держать одинаковыми.
Кадр: `[тип][seq][N][данные N][CRC-8][хвост '$']`.

- **Подтверждение — ответ на хвост.** ACK байта F4 ставит аппаратно до того, как программа
  его увидит (ES0182 2.10.2), поэтому решение по CRC отдаётся на следующий байт — хвост:
  ACK = пакет принят, NACK = модуль повторит через 10 мс.
- **Срок решения — 8 бит хвоста (~80 мкс).** Удержание SCL у F4 наступает только после ACK
  следующего байта, поэтому прерывание I2C1 с приоритетом **1** (выше ETH 5), CRC
  считается по ходу приёма, по байту CRC — только сравнение. Счётчик `late` в статистике
  должен оставаться 0.
- **После NACK флаг STOPF не ставится** (RM0090), бит ACK возвращается в RXNE отвергнутого
  байта и, для страховки, в `keypad_poll()` при свободной шине.
- **Повтор с тем же seq** (модуль не получил наш ACK) отбрасывается, пропуск seq пишется в лог.
  Пакет `START` (после сброса модуля) начинает нумерацию заново.

## Типы пакетов

| Тип | Данные | Лог (USART1) |
|---|---|---|
| `GROUP` 0x02 | `[причина][символы 0-9, A-D]` | `[kbd] #5 GROUP enter: "1A2B"` |
| `CANCEL` 0x03 | `[причина]` | `[kbd] #6 CANCEL timeout` |
| `KEY` 0x01 | `[бит 7 нажата + ASCII]` — только если модуль собран с `LETTERS_KEY` | `[kbd] #7 KEY A down` |
| `START` 0x04 | `[версия ПО][MCUSR]` | `[kbd] #1 START fw 2, reset cause MCUSR 0x01` |

Причины: 1 `#`, 2 предельная длина (16), 3 пауза (10 с), 4 `*`.
MCUSR: 0x01 питание, 0x02 RESET, 0x04 просадка питания, 0x08 сторожевой таймер.

## Использование

```c
static void on_keypad(const KeypadPacket *p)
{
  if (p->type == KBD_PKT_GROUP && p->data[0] == KBD_END_ENTER)
  {
    /* p->data[1..p->len-1] - набранные символы, p->len - 1 штук */
  }
}
...
keypad_set_handler(on_keypad);
```

Обработчик вызывается из `keypad_poll()` (главный цикл), не из прерывания. После него
пакет в очереди затирается — пароль в памяти не остаётся.

## Страница дисплея «I2C KBD»

Кнопкой страниц (PC6) выбирается страница `I2C KBD 0x30`. На ней по строке на каждый принятый
пакет, новые снизу; когда 18 строк заполнены, список прокручивается. Строки копятся и тогда,
когда открыта другая страница.

В заголовке — адрес STM32 на шине клавиатуры (`I2C KBD 0x30`). Строка под ним — счётчики:
`RX` — сколько раз к этому адресу обратились (передач), `OK` — принятые пакеты,
`ERR` — CRC + оборванные кадры + ошибки шины (BERR/ARLO/OVR). Норма: `RX` = `OK`, `ERR 0`.
`RX 0` при работающем модуле — модуль до STM32 не доходит (проводка, SDA/SCL, подтяжки)
или в модуле не та прошивка (`uarttest` в I²C не пишет).

| Строка | Цвет | Что |
|---|---|---|
| `#12 E 1234567890` | зелёный | GROUP; конец: `E` — `#`, `M` — 16 символов, `T` — пауза, `C` — `*` |
| `#13 CANCEL TIMEOUT` | жёлтый | CANCEL и причина |
| `#1 START FW 2 RST 02` | голубой | сброс модуля, MCUSR |
| `#7 KEY A DOWN` | белый | KEY (модуль собран с `LETTERS_KEY`) |
| `LOST 2`, `CRC 3 LATE 0` | красный | пропуск seq, изменились счётчики ошибок |

При `KEYPAD_LOG_TEXT 0` вместо символов группы — их число.

Следующая страница, `KBD HELP`, — краткая расшифровка этих строк на самом дисплее.

## Листание страниц с клавиатуры

Обработчик в `Core/Src/main.c` (`on_keypad()`): `#` без символов — следующая страница,
1–3 цифры и `#` (`3#`, `12#`) — страница с этим номером (как в индикаторе `n/N`); номер,
которого нет, игнорируется. Всё остальное — обычный ввод: пароли не короче 4 цифр или
начинаются с буквы, с командами не пересекаются. Цифры идут **перед** `#`: модуль
отправляет группу только по `#`.
Кнопка страниц (PC6) работает как раньше.

## Настройки — `Inc/keypad_config.h`

| Параметр | По умолчанию | |
|---|---|---|
| `KEYPAD_IRQ_PRIORITY` | 1 | приоритет I2C1_EV/ER; должен быть выше остальных |
| `KEYPAD_LOG_TEXT` | 1 | 1 — печатать набранное, 0 — только число символов (для паролей) |
| `KEYPAD_QUEUE_LEN` | 8 | пакетов между прерыванием и главным циклом |
